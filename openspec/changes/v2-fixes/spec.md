# v2-fixes: 备婚网站四项修复

## 问题描述
用户反馈4个问题需要修复。

## 修复项

### 1. 首页"本月待办"支持勾选和备注
- 首页的"本月待办任务"卡片中的子任务需要能勾选完成/取消
- 勾选状态需要影响总进度和关键任务进度
- 每个子任务需要支持添加备注（和时间线页面一样）
- 数据使用 localStorage 持久化（复用现有的 `wedding-completed-subtasks` 和 `wedding-subtask-notes`）

### 2. 备注UI美化
- 当前备注输入框样式粗糙，需要美化
- "添加备注..." 占位文字应该更不显眼，不要用黄色背景
- 设计方案：
  - 无备注时：显示灰色小字"备注"，鼠标悬停才显示可编辑
  - 有备注时：用浅粉色底色小字显示备注内容
  - 编辑状态：圆角输入框，粉色边框，白色背景
  - 整体紧凑，不要太占空间

### 3. 预算板块可用
- 当前预算控制表页面（/budget）数据不完整或不可用
- 需要补充完整的预算项：
  - 大项分类：婚庆仪式、场地餐饮、服饰美容、婚照婚品、交通住宿、其他
  - 每个大项下有分项
  - 需要能编辑预算金额和实际花费
  - 自动计算差额
  - 所有数据使用 localStorage 持久化
- 参考小红书模板：大项、分项、预算、实际花费、备注

### 4. 甘特图支持2026年
- 当前甘特图年份选择器没有2026年选项
- 默认应该显示2026年
- 数据已经是2026年的了，只需要修复年份选择UI
